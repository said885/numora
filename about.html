About Numora

What this site is

Numora is a collection of 13 free online calculators — loans, mortgages, compound interest, BMI, unit conversion, dates, discounts, tips, percentages, rent splitting, fuel costs, grades and age. Every tool is built to answer one question accurately and get out of the way: no accounts, no pop-ups, no waiting.

How it works — and why that matters for privacy

All calculations run entirely in your browser, in plain HTML, CSS and JavaScript. The numbers you type are never sent to a server, never stored, and never associated with your identity. There is no backend database to breach and no user profile to sell — the only thing this site knows about you is what every web server knows: that a page was requested. That data is covered by the privacy policy.

Every formula used is the standard, published one, and each calculator page explains it so you can verify the arithmetic yourself. The code is served from GitHub Pages; the source lives on GitHub.

How it is funded

Numora is free and stays free. It may display advertising and may include clearly marked affiliate links, as described in the affiliate & advertising disclosure. Commercial relationships never influence the formulas, the explanations or which tools get built.

Limitations, stated plainly

These calculators provide estimates for planning purposes. They are not financial, medical, legal or academic advice. Loan and mortgage figures should be confirmed against your lender's official schedule; BMI is a screening statistic, not a diagnosis; grading policies vary between institutions. Where a rule depends on your jurisdiction or institution, the official document wins.

Contact

This is an independent, solo-maintained project. The fastest way to reach it — bug reports, feature requests, corrections to a formula — is through the GitHub issue tracker.
